# 生物発光 発光生物・発光機構クイズ

35種の発光生物とその発光機構について学べる3モードのインタラクティブクイズアプリ。

## 機能

- **生物名当てクイズ**: 生物の説明と発光機構から4択で生物名を当てる（ホタル・チョウチンアンコウ・オワンクラゲ等）
- **発光機構マッチング**: 生物名から生化学的発光経路を4択で選ぶ（ルシフェリン系・GFP・クオラムセンシング等）
- **○×クイズ**: 生物発光に関するトリビア・科学的事実の正誤を判定する12問セット
- 解答後に発光波長（nm）と発光色スウォッチを表示して視覚的に確認できる
- 3モード別ハイスコアをlocalStorageに保存
